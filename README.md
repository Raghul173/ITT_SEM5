# ITT on C Programming Lab 🚀

Repository for C Programming laboratory practicals, covering procedural programming fundamentals, algorithm logic, dynamic memory management, and file systems.

---

## 📋 Practical Experiments

This repository contains solutions and implementations for the following 10 structured topics:

| S.No | Experiment Name | Focus Area | Core Concepts |
| :--- | :--- | :--- | :--- |
| **01** | Programs using simple statements | Foundational Execution | Variables, Basic Data Types, I/O (`printf`, `scanf`) |
| **02** | Programs using decision making statements | Conditional Logic | `if-else` branches, `switch-case` blocks |
| **03** | Programs using looping statements | Iterative Logic | `for`, `while`, `do-while` loops |
| **04** | Programs using user defined functions | Modularity | Function declarations, definitions, parameter passing |
| **05** | Programs using recursive functions | Call Stack Operations | Base conditions, self-calling structures (e.g., Fibonacci) |
| **06** | Programs using arrays | Homogeneous Data | Linear sequence memory, multi-dimensional array tracking |
| **07** | Programs using string functions | Character Buffers | String manipulations using `<string.h>` library |
| **08** | Programs using pointers & dynamic allocation | Memory Management | Reference tracking, `malloc`, `calloc`, pointer arithmetic |
| **09** | Programs using structures and unions | Heterogeneous Data | Custom data types using `struct` and `union` constructs |
| **10** | Programs using files | Persistent Storage | File handling streams (`fopen`, `fclose`, `fprintf`, `fscanf`) |

## 🚀 Compilation and Execution

To compile and run any `.c` program using your terminal, use the following steps:

1. **Clone the repo:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate to the target directory:**
   ```bash
   cd 02_Decision_Making
   ```
3. **Compile the file:**
   ```bash
   gcc branch_logic.c -o program
   ```
4. **Run the executable:**
   * **Linux/macOS:** `./program`
   * **Windows:** `program.exe`
